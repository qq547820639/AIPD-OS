# F-DFM-01 第 24 片：壁厚的第二条量法（沿面法向）与一条被实测推翻的旧话

对应 `cad.dfm_dfa`。动因不是设想，是量出来的：写这片之前先在真 OCCT 上量了一块
**3mm 厚、绕 Y 转 45° 的板**，原来的三轴网格射线给出 **1.00mm**。
而 `dfm.py` 的 docstring 与报告 caveat 里都写着「斜置薄壁会**测厚不测薄**」——
这句关于误差方向的话是错的，实测两个方向都有。一个方向性偏差挂在 advisory 上，
读报告的人恰好朝错误的方向放心。

## 一、选型检索（本机真实读取 + 外部文档，访问日 2026-09-25）

按目标要求先比成熟实现，四路候选：

| 候选 | 它实际做什么 | 能不能复用 |
|---|---|---|
| OCCT `BRepOffsetAPI_MakeThickSolid` | **建模**：把实体掏空成壳（`Intersection` 官方注明「没实现完、不建议用」、`SelfInter` 「未实现」）。OCCT 里根本没有「壁厚测量」这一族工具（子代理把 V7_7_2 整棵树按 "Thick" 搜过，只命中这一个文件） | 不能：它不出数 |
| FreeCAD `Part/PartDesign Thickness` | 同样包在 `MakeThickSolid` 上，是抽壳功能。**没找到** FreeCAD 的「最小壁厚报告/热图」 | 不能：没有可借的分析件 |
| CATIA 壁厚分析 | **同时给了两档**：默认 Sphere（能放进零件的最大球直径）与可选 Ray（沿边界法向向内的一条射线）。其文档明写 Ray 模式「误差可能超过容差，尤其尖边处」，并提供 "No Sharp Edge" 掩膜 | 可借**思路**：法向射线是厂商认可的次档做法，且必须掩尖边 |
| libigl `shape_diameter_function` / `signed_distance`、BoneJ 的局部厚度 | 网格侧的标准定义：**最大内接球**（SDF/距离变换）；SDF 用绕数判内外，鲁棒 | 可借定义与「先判内外再收段」的做法，但本仓是 B-Rep 不是网格，直接引 libigl 要拖入整条 C++ 依赖链 |

结论：**不新增依赖，借 CATIA 的「法向射线 + 尖边掩膜」与 SDF 那一路的「先验证在不在材料内」**。
实现原语全在仓内已有的 OCP 上：`BRepGProp_Face.Normal`、`BRepAdaptor_Surface` 参数域、
`IntCurvesFace_ShapeIntersector`（第 19 片就用了）、`BRepClass3d_SolidClassifier`。

本机实测到的三处坑（都改掉了实现）：
1. `Normal()` 出来的向量**未必是单位向量**（源码里是 `D1U × D1V`）⇒ 用前 `Normalize()`；
2. 它的**符号跟面的 Orientation 走，不是「朝外」**（`mySReverse` 由 `REVERSED` 决定）
   ⇒ 两个方向 `±N` 都得走一遍（变异电池 W2 就是「只走一边」，球那条用例当场红）；
3. 曲面极点/奇异处法向可能退化，而 `gp_Vec::Normalize()` 对零范数**直接抛
   `Standard_ConstructionError`** ⇒ 先判 `Magnitude()`，退化就跳这个采样点（不猜）。

## 二、判据

`_face_normal_thickness()` 逐**实体**（不是对整个复合体分类：两个不相连的实体不该互相
把对方内部当成「材料内」）：面的参数域**中间 60%** 上采样，沿 ±法向取第一段命中，
两道验证都过才收——**中点分类为 IN** 且 **出射点（再往前 1e-3）分类为 OUT**。

聚合口径：**两法各量各的，`min_mm` 取较薄者**，`axis_min_mm` / `normal_min_mm` 都留在读数里。
不是「谁新听谁的」，也不是「谁稳听谁的」：

| 夹具 | 三轴 | 法向 | 说明 |
|---|---|---|---|
| 3mm 斜板（45°）@0.5 | **1.00** | 3.00 | 三轴被棱角附近的短弦带跑 |
| 同一块 @1.0 / 2.0 / 5.0 | 2.02 / 3.00 / 3.00 | 3.00 恒定 | 三轴随间距跳，法向不随网格变 |
| 金样品 `bracket.step` | **2.00** | 3.73 | 法向采样稀，**漏掉**了三轴抓到的薄特征 |
| 1mm 球皮 | 1.00 | 1.00 | 两法一致 |
| 球 r5 / 圆柱 r5×20 | — | 10.00 / 10.00 | 极点不炸，反向不漏也量得出 |

因为壁厚那两条规则（金属 0.8 / 塑料 1.5，来源 HLH Rapid）是 **advisory**（不阻断就绪），
取较薄者的代价只是多提一次「找制造方看看」；反过来取较厚者会把墙说厚——那才是不能犯的。

**空腔不是墙**：20 见方的块里挖一条 0.5mm 宽、四周全封闭的槽，裸取「第一条命中」会把
0.5 的槽宽读成壁厚（那是空气）。分类器那两道验证把它挡掉，量到的 5.000 是
「槽端到块边」那段实打实的肉（槽 x∈[-5,5]、块边 x=10）。这条单独有常驻用例。

  换成上面那张实测表说的事。

三条存活各自的解释，不粉饰：
- **W7**：本仓现有夹具造不出零法向的采样点（球/圆柱/环面都试过，`samples_degenerate_normal` 恒 0），
  所以没有任何读数会为它改变。这条守卫的价值是**防炸**，而危险是真证过的
  （`gp_Vec(0,0,0).Normalize()` 抛 `Standard_ConstructionError`，有专门一条用例钉这个），
  只是「谁会在真模型上踩到」还没量到。留着，记为未开火。
- **W8 / W9**：两道材料验证**互为冗余**——单独撤任一道，本批夹具的读数都不变；
  一起撤（W3）才变。这是一个读数，不是一句托辞：它说明这道关卡是双保险，
  也说明「单独验任一道」在今天没有独立的判据价值。要拆成各管一半，得找一个
  「中点在材料内但出射点仍在材料内」与一个「中点在外而出射点在内」的形态各一个，本批没有。

## 六、这一片没做的事

- 不做**最大内接球**那一档（CATIA 的默认模式、网格侧的标准定义）。它对采样密度的要求高得多，
  且本仓在 B-Rep 上没有便宜的精确算法；两法交叉已经能把disagreement摆到人面前。
- 不做沿面法向的自适应加密（现在每面最多 12×12）：那会把「法向漏检」压小，但也把
  「两法谁薄谁赢」的语义糊掉。要做得先定报告里以谁为准。
- 没给 `axis_min_mm` 与 `normal_min_mm` 分歧过大时加一条判定（比如差 2× 就提示
  「模型有斜壁，两法不一致」）——那是**新阈值**，本仓不自己发明数。
