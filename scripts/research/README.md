# Multi-source paper search

Vendored from the user-provided ResearchStudio paper-search skill under MIT License. Run `python search_papers.py --help` from this directory. The aggregator supports arXiv, DBLP, OpenAlex, OpenReview, Semantic Scholar and Crossref, with concurrent source workers, retries, deduplication and relevance ranking.

The main AIPD Skill should use these results to create evidence records, not present every search hit as an accepted engineering fact.
