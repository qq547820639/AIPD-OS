# 事实、证据与置信度政策

## 核心对象

- **Fact**：项目当前采用的结构化结论或参数。
- **Evidence**：支持或反驳 Fact 的可追溯材料。
- **Assumption**：为继续工作而暂时采用、尚未充分验证的前提。
- **Decision**：产品所有者批准的价值或资源权衡。
- **Risk**：不确定事件及其影响、概率、缓解和所有者。

## 证据状态

| 状态 | 含义 | 允许使用方式 |
|---|---|---|
| V | 实体测试/正式文件验证 | 可作为最终规格，注明条件 |
| S | 实际仿真支持 | 可作为仿真性能，不能称实测 |
| C | 可复核计算 | 可作为计算值，保留公式和输入 |
| E | 权威外部证据 | 可支持范围和设计依据，不直接证明本产品表现 |
| A | AI假设 | 仅用于设计目标/待验证项 |
| P | 等待供应商确认 | 不得写成承诺 |
| T | 等待实体测试 | 不得写成通过 |
| R | 已废弃 | 不得进入新交付物 |

## 每条事实的最小字段

- 唯一键、名称、值、单位、容差/范围；
- 测试或适用条件；
- 状态与置信度；
- 来源和证据 ID；
- 适用产品版本；
- 生效/废弃时间；
- 受影响交付物。

## 证据层级

1. 法规、标准原文、正式证书、实验原始数据；
2. 同行评审论文、权威机构报告、可复现技术文档；
3. 厂商数据表、正式报价、供应商质量文件；
4. 可信行业资料和专业媒体；
5. 模型推断或二手聚合资料。

低层级证据不得单独支撑高风险最终结论。

## 引用与摘录

- 记录题名、作者/机构、年份、永久标识符、URL、访问日期、关键结论和适用限制。
- 区分来源直接陈述与 AI 推断。
- 避免复制长篇受版权保护原文；保存简短必要摘录和准确摘要。
- 论文结论必须记录研究对象、样本、工况和与当前产品的可迁移边界。

## 冲突处理

1. 不静默覆盖旧值；创建新版本并记录差异。
2. 比较证据质量、条件和时间。
3. 能通过计算/检索解决则自动解决。
4. 若冲突会改变已批准核心目标或高风险结论，生成决策包。
