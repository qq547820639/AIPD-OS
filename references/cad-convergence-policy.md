# CAD 收敛与防跑偏策略

## 1. 先定义终点

每个 CAD 任务在建模前必须有 `CAD Contract`。终点不是“生成了 STEP”，而是：

- 所有硬约束通过；
- 必需交付物存在；
- 没有未处理回归；
- 高风险假设已消除、隔离或明确转入测试；
- 软目标达到发布阈值，或继续优化已无显著收益；
- 结果与事实库、BOM、接口和批准决策一致。

## 2. 硬约束与软目标分离

### 硬约束

任何一项失败都不得发布，例如：

- STEP/实体无效；
- 关键尺寸、公差或接口不符；
- 零件穿透、运动干涉或安全间隙不足；
- 关节/装配基准错误；
- 必需零件、采购件或释放机构缺失；
- 壁厚、孔边距、弯曲半径等违反选定工艺规则；
- CAD 参数使用了未经批准或无状态标记的数据。

### 软目标

可以权衡优化，例如：

- 质量、零件数、预计成本；
- 装配工序、紧固件种类；
- 外形连续性和对称性；
- 标准件比例；
- 维护可达性；
- 与产品手册视觉意图的一致性。

## 3. 单轮循环

`Brief → Contract → Plan → Source → STEP → Deterministic Inspection → Snapshot Review → Score → Repair/Continue/Release`

每轮必须记录：

- 输入事实版本；
- 源码版本和导出文件；
- 实际运行的检查；
- 失败项和证据；
- 修改内容；
- 是否出现回归；
- 软目标分数；
- 下一轮目标。

## 4. 自动判定

默认判定规则：

- 缺少必需交付物：`repair`；
- 任一硬约束失败：`repair`；
- 失败源自互相冲突的已批准硬约束：`owner_decision`；
- 硬约束通过但软目标低于阈值：`continue_optimization`；
- 达到最大内部迭代仍无显著改善：分析是否为需求冲突；仅在需要改变目标时 `owner_decision`；
- 硬约束全过、无回归、证据完整、软目标达标：`ready_for_internal_release`；
- 开模、正式发图和生产冻结仍需不可逆行为放行。

默认软目标发布分数为 0.90。默认“显著改善”为综合分数提升至少 0.01。阈值可由项目定义覆盖，但不得在迭代中为了过关而自行降低。

## 5. 防止局部最优

- 骨架和接口未稳定前，不优化圆角和外观细节；
- 装配检查未通过前，不制作最终工程图；
- 不用扩大公差掩盖定位错误；
- 不用增加材料厚度替代传力路径分析；
- 不以视觉快照替代几何测量；
- 不以单一姿态通过替代全工作范围检查；
- 不以 STL 网格作为生产主模型；
- 不因生成成功就跳过快照和回归检查。

## 6. 回归策略

每次修复至少复跑：

1. 当前失败项；
2. 与修改特征直接相邻的接口和尺寸；
3. 所有安全相关硬约束；
4. 上一轮已经通过但容易受影响的项目；
5. 主装配快照。

## 7. 发布标准

CAD 发布包至少包含：

- 参数化源码；
- 主 STEP；
- 必要的 DXF/2D 图纸；
- 采购件来源和版本；
- CAD Contract 与验收矩阵；
- 几何检查和尺寸报告；
- 快照；
- 参数—事实 ID 映射；
- BOM 料号映射；
- 已知限制和待测试项；
- 版本、哈希和变更记录。
