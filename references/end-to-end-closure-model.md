# 端到端闭环判定模型

“流程写完”不等于“运行打通”。AIPD 将闭环分成四层：

1. **架构闭环**：阶段、状态、证据、决策、交付契约和工具接口存在并通过离线测试。
2. **工具运行闭环**：实际调用研究、文档和 CAD 工具；CAD 必须产生真实 STEP、检查报告和快照。
3. **项目数字闭环**：针对一个真实产品，从输入到手册、CAD、生产资料与发布包完整运行。
4. **物理闭环**：样机、测试、供应商、工艺和认证真实执行并回流。

只有 `scripts/e2e_acceptance.py` 对项目工件返回 `full_digital_chain_ready=true`，才能使用“数字全链路已打通”。接口设计、提示词、模拟测试或空占位文件都不构成闭环证据。
