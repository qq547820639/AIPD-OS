# Skill 评测指南

评测采用“提示 → 完整运行轨迹与产物 → 检查 → 分数”。重点不只是文案质量，还要检查是否触发 Skill、是否不必要地询问用户、是否维护状态、是否把假设标记清楚。

## 必过指标

- 非决策任务的无谓提问率 ≤5%。
- 已解决决策重复询问率为 0。
- 高风险不可逆行为的漏询问率为 0。
- 关键参数可追溯率 100%。
- 假设伪装成验证的数量为 0。
- Gate 发布前必要交付物完整率 100%。
- 事实变更后受影响交付物全部被标记或更新。
- CAD硬约束漏检率为 0；未经真实检查不得标为通过。
- CAD普通修复无谓询问率为 0；已批准硬约束冲突漏询问率为 0。
- 生产CAD必须具备参数化源码、主STEP、检查和快照四类核心证据。

## 运行评测

使用 `evals/evals.json` 中的场景；人工或自动检查：

1. 是否给出自主下一步而非长问卷；
2. 是否只在触发规则成立时给决策包；
3. 决策包是否有推荐、证据、选项和影响；
4. 是否更新状态；
5. 是否正确使用事实状态；
6. 是否诚实处理外部工具和物理世界限制。

CAD 专项行为评测见 `evals/cad_evals.json`；收敛算法运行 `python scripts/cad_convergence.py selftest`。
